# Findings — App shell, Dashboard, Login/Lock/First-run

Size note: `src/styles/globals.css:412-420` remaps `text-[9px]`→12px, `text-[10px]`→13px, `text-[11px]`→14px (rem, so they follow the font slider). `[11px]` therefore meets the 14px floor but should still become `text-xs` so the scale is one system; `[9px]`/`[10px]` are below the floor. `text-[12px]` is NOT remapped (true 12px). Recharts `fontSize={11}` props are SVG attributes and are NOT remapped either (true 11px).

- `text-[10px] uppercase tracking` micro-labels as section headers and form labels: GlobalSearch.tsx:217, MoreMenu.tsx:115, Shortcuts.tsx:48, TimeRange.tsx:93, widgets.tsx:185/263/436, LoginPage.tsx:327/342, FirstRunWizard.tsx:508. One shared `<Label>` / `<SectionLabel>` (`text-xs font-medium`, sentence case) in `src/components/ui/`.
- `text-[11px]` sub-lines everywhere (~25 in these files) → `text-xs` mechanically; add a lint rule (regex on `text-\[\d+px\]`) so new ones stop appearing. `text-[12px]` (LoginPage.tsx:374, FirstRunWizard.tsx:368) escapes the globals.css remap.
- Hand-rolled 24–32px icon buttons instead of `Button size="icon"`: Titlebar `IconBtn size-8` (:372), MoreMenu trigger `h-8` (:92), Widget.tsx:56/64/83 `size-6`, Dashboard.tsx:272/280 `size-6`, Kpi.tsx remove `size-6` (:118+), CustomizePanel close `size-8`. Use the primitive (36px) with a `title`.
- Hard-coded `'en-GB'` date/time ignores the language toggle: Dashboard.tsx:50, PendriveBackup.tsx:116, LockScreen.tsx:92-99. One `formatDate(date, style)` helper in `src/lib/` reading `useLang()`.
- Interpolated sentences the whole-node Bangla layer cannot match: GlobalSearch.tsx:249, DuesPanel.tsx:108/162, widgets.tsx:335, Dashboard.tsx:293, TimeRange.tsx:135, LockScreen.tsx:112, FirstRunWizard.tsx:234. Keep the words as their own node and the value separate, or give each variant a full dict key.
- Raw data keys rendered as UI text (`{r.type}` and `{parsed.scope}` in search, `{s.status}` in Recent Sales), often with CSS `uppercase`/`capitalize`. One `labelFor(kind, key)` map in `src/lib/` shared by search, badges and tables.
- Duplicate entry points: New sale/purchase/expense/product/customer in sidebar + dashboard tiles + Shortcuts; Profit in KPI + tile + Shortcuts; Price Groups vs Customer Groups. One home per action: sidebar for places, dashboard tiles for ~6 daily jobs, nothing else.
- Overlays not on the shared primitives: CustomizePanel.tsx (own drawer, no Esc); Titlebar account menu and MoreMenu (own portals, no initial focus/arrow keys). Move CustomizePanel onto `Drawer`; give the two titlebar menus a shared `MenuPanel` with focus-first-item and ↑/↓.
- `font-mono` for money (Kpi.tsx:87, ProfitDetail.tsx, widgets.tsx:217, DuesPanel.tsx:153): wider and inconsistent with money elsewhere. Use `tabular-nums` in the UI face; keep mono for SKU/barcode only.
